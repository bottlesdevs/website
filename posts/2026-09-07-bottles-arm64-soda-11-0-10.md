Bottles 67.4 is now available for ARM64 Linux as a test release through cpak. It includes Soda 11.0-10, which fixes Battle.net, adds host OpenXR support and gives Adaptive Launch a better memory across separate sessions.

Adaptive Launch watches which modules a program needs early and prepares the recurring ones for its next start. Enable it in **Bottle Preferences**, under **Performance**, then use the program normally while Soda builds its profile.

## Bottles gets ARM64 support

The Bottles cpak package can now be installed on ARM64 Linux systems. cpak selects the correct package automatically, while Soda provides native ARM64 and ARM64EC support and bundles FEX for x86 and x86_64 Windows programs.

ARM64 support is currently a test release available only through cpak. Flathub remains x86_64 for now.

To try it, install Bottles from the [cpak Store](https://cpak.it/store/Utilities/github.com/bottlesdevs/bottles) or run:

```bash
cpak install github.com/bottlesdevs/bottles
```

## Soda 11.0-10 fixes Battle.net and adds OpenXR support

Battle.net no longer crashes when XInput starts without a Steam game ID. Update to Soda 11.0-10 and launch it again; there is no workaround or extra setting to apply.

Soda can also connect 64-bit Windows OpenXR applications directly to a Linux runtime such as Monado or WiVRn, without requiring Steam or SteamVR. Bottles enables the connection when the host runtime is available.

Adaptive Launch now learns across separate sessions, keeps the modules that repeatedly matter during startup and migrates profiles created by earlier Soda versions. Soda 11.0-10 also adds the MS-ICU runtime used by .NET applications for time zones and Unicode data, and improves WMV and WMA playback when Proton's media converter database is unavailable.

## More fixes in Bottles 67.4

Runner updates keep the Windows username configured in each bottle, pure 32-bit prefixes continue to work, and Windows applications can open long URLs through `ShellExecute`. Fullscreen presentation for child windows has also been corrected.

Bottles 67.4 updates the fallback Components catalog shipped inside the cpak package. Bottles 67.3 on Flathub already receives Soda 11.0-10 through the live Components catalog, so Flatpak users do not need an application update for these runner fixes.
